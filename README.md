# ClinicalTrials.gov Database

A skill for querying and analyzing clinical study records through the ClinicalTrials.gov API v2.

## Capabilities

- Search studies by condition, intervention, location, status, phase, and other criteria.
- Retrieve detailed study records using NCT identifiers.
- Review study design, eligibility, recruitment, locations, sponsors, and outcomes.
- Export and organize trial data for research workflows.
- Use the included reference and script for supported query operations.

## Usage

Use this skill when locating clinical studies, reviewing trial characteristics, tracking sponsors, or preparing research datasets. Follow the API workflow and field guidance in `SKILL.md` and its supporting files.

## Data interpretation

Registry records describe submitted study information and may change over time. Check the record's update date and verify important details against the live registry. Search results do not establish trial suitability or patient eligibility. Patient matching and care decisions must be handled by qualified professionals.
